# 📥 BRK App auf Mac downloaden

**Super einfach - nur 2 Schritte!**

---

## 📥 SCHRITT 1: ZIP herunterladen

1. **Öffne diesen Link auf deinem Mac:**
   ```
   https://github.com/m2cnknny9d-eng/brk-app/archive/refs/heads/main.zip
   ```

2. **Die Datei wird heruntergeladen:**
   ```
   brk-app-main.zip
   ```
   (Zu Downloads Ordner)

---

## 📂 SCHRITT 2: ZIP entpacken

1. **Gehe zu:** "Downloads" Ordner
2. **Doppelklick auf:** `brk-app-main.zip`
3. **Wartet kurz...**
4. **Fertig!** Der Ordner `brk-app-main` entpackt sich

---

## ✅ FERTIG!

Du hast jetzt:
```
~/Downloads/brk-app-main/
```

Diese Ordner brauchst du für:
- Terminal Befehle
- GitHub Upload
- Vercel Deploy

---

## 🎯 Nächster Schritt:

Folge jetzt: **GITHUB_UPLOAD_KURZ.md**

Dort werden die Terminal-Befehle mit dem richtigen Pfad erklärt!
